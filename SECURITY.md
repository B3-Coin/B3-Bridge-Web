# Security policy

## Do not share secrets

The B3 Bridge website will never ask for a seed phrase, private key, BLS secret key, wallet password, or B3 data-directory access. Report any copy that asks for one as malicious.

## Before reporting

Include the website CID or URL, browser and wallet version, Ethereum transaction hash when one exists, and the exact error text. Never include private keys or recovery words.

## Launch gate

Deposits remain disabled until contract source publication, verifier initialization, live validator readiness, an independent contract/cryptography audit, an end-to-end rehearsal, and explicit production approval are all complete.
